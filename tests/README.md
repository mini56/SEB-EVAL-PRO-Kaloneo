# Tests de migration

Aucun exercice historique n'est déclaré compatible avec la nouvelle architecture sans tests.

Pour chaque exercice migré :

1. test isolé ;
2. sauvegarde ;
3. restauration ;
4. correction ;
5. résultats ;
6. abandon avec et sans NE ;
7. Replay ;
8. contribution au bilan ;
9. intégration dans un parcours ;
10. reprise de parcours ;
11. fin normale ;
12. clôture Administrateur.

Des parcours courts seront construits d'abord, puis des parcours de plus en plus complets jusqu'au parcours intégral.
