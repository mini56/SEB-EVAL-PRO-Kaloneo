# SEB EvalPro KALONÉO — décisions PILOTE 8

Date : 2 octobre 2026

Le PILOTE 8 repart strictement du PILOTE 7 validé et ne modifie pas les exercices KALTEST ni leurs barèmes.

## Page candidat — prise en main

- Les trois blocs de droite (chronomètre, calculatrice, audio) sont remontés.
- Le badge « 2 » du chronomètre ne doit plus être coupé.
- Chronomètre : « Démarrer le chronomètre » est vert ; « Arrêter le chronomètre » est rouge.
- Le bouton du test calculatrice reprend exactement le bouton calculatrice utilisé dans les exercices réels : même classe KALONÉO et libellé « Ouvrir la calculatrice ».
- Le test souris maison + voiture reste inchangé.
- Le test audio reste inchangé.
- Ces essais restent non notés et n’entrent dans aucun score ni bilan.

## Bouton écran d’accueil

- Le bouton flottant « Afficher l’écran d’accueil » doit utiliser le style KALONÉO : fond clair, contour bleu KALONÉO, arrondis et ombre cohérents avec le design system.
- Son fonctionnement ne change pas.

## Page Introduction

- Le doublon de test calculatrice est supprimé.
- L’ancienne image de couverture est retirée de cette page ; elle pourra être réutilisée ailleurs plus tard.
- Elle est remplacée par une mini vidéo/animation locale illustrant une personne qui arrive devant l’usine, avance vers l’entrée puis entre dans le bâtiment.
- La séquence démarre automatiquement dès l’affichage de la page.
- Elle est silencieuse.
- Elle dure environ 7 secondes.
- Elle n’est lue qu’une seule fois par session candidat et ne tourne jamais en boucle.
- Après la lecture, l’écran reste sur l’image finale avec le message « Bienvenue ».
- Le bouton « Commencez l’évaluation » reste disponible sous la séquence.

## Anti-régression

- Barre Administrateur du PILOTE 6/7 conservée.
- Bilan et ses deux boutons Fermer conservés.
- Logique Quitter / Fermer la session active du PILOTE 7 conservée.
- Exercices, résultats, bilan, abandon, calculatrice réelle et pont KALTEST vers le socle historique conservés.
